# Varsha Teddy Studio

A plain HTML/CSS/JavaScript handmade teddy website for Porbandar.

## Included
- Scroll-driven cinematic hero using the supplied 177 JPG frames.
- Responsive canvas rendering for desktop and mobile.
- Handmade/custom teddy collection section.
- Custom order section and enquiry form.
- WhatsApp enquiry flow placeholder.
- No framework or build step required.

## Run
Open `index.html` in a browser. For best results, use a simple local server because the browser may restrict local image loading when opening the HTML directly.

Example:
`python -m http.server 8000`

Then open `http://localhost:8000`.

## WhatsApp
Open `script.js` and replace `YOUR_WHATSAPP_NUMBER` with the business WhatsApp number in international format without `+` or spaces.

## Sequence frames
The supplied sequence is in `images/teddy-sequence/` as `frame-001.jpg` through `frame-177.jpg`.

Note: the supplied frames contain the PixVerse watermark. Replace the sequence with a clean export before publishing if possible.
